## 我實測的最低充值金額

我用同一個帳號分別試咗兩種付款方式：

- 信用卡（Visa）：最低充值顯示為 10 美元，即大約 78 港元。
- 支付寶（Alipay）：最低充值顯示為 50 元人民幣，換算約 55 港元。

兩者都可以自訂金額，但低於最低值就撳唔到確認。要注意嘅係，如果你用香港信用卡，發卡銀行可能收 1% 至 3% 外幣交易手續費；支付寶就可能收跨境手續費。我試過用一張免外幣手續費嘅香港信用卡，10 美元實際扣款約 78.5 港元，算係咁。

如果你只係想試玩 API，建議先充最低金額，再用細模型做測試。想知 API Key 權限同用量限制，可以睇我之前寫嘅 [DeepSeek API Key 申請與限制筆記](/posts/deepseek-api-key-and-limits/)。

## 香港用戶慳錢充值三步曲

### 第一步：揀啱付款方式

登入 platform.deepseek.com，入去「充值」頁面。香港用戶通常有兩個選擇：信用卡或支付寶。如果你有內地支付寶戶口，用支付寶可能平少少；如果冇，就用免外幣手續費嘅香港信用卡。

### 第二步：設定自訂金額

唔好揀預設套餐，直接輸入你想充嘅金額。我試過輸入 10 美元，系統接受。如果你想再保守啲，可以睇下有冇更細選項，但實測所見最低就係 10 美元（信用卡）。

### 第三步：確認匯率與手續費

付款前，頁面會顯示實際扣款金額。香港用戶要留意匯率係以美元計價，信用卡公司會用自己嘅匯率結算。我會建議喺付款前先開一個外幣戶口或者用多幣種信用卡，慳返 1% 至 2%。

## 餘額查詢與用量提醒

充值完，點知仲有幾多錢？你可以喺 platform.deepseek.com 嘅「用量」頁面睇到餘額同埋每日消耗。我習慣喺專案入面加一個簡單嘅檢查步驟：用 API 回傳嘅錯誤碼判斷係咪餘額不足。例如回傳 402 或者類似嘅付款相關錯誤，就代表要充值。

另外，你可以喺平台設定用量提醒，當餘額低於某個金額就發電郵通知。我測試時發現，提醒設定要手動開啟，默認可能係關閉。至於具體錯誤碼列表，以官方文檔為準。

如果你想用自動化工作流監控餘額，可以參考 [DeepSeek API 重試與錯誤處理指南](/posts/deepseek-api-retry-guide/)，入面有講點樣區分不同錯誤類型。

## 常見問題

**Q1：最低充值金額係固定嘅嗎？**

唔係。我實測 2025 年 7 月嘅最低金額係信用卡 10 美元、支付寶 50 元人民幣，但呢個數字會隨官方政策調整，建議充值前睇清楚頁面顯示。

**Q2：香港信用卡會唔會收額外手續費？**

多數會，通常 1% 至 3% 外幣交易手續費。建議用免外幣手續費嘅卡，或者比較不同付款方式嘅總成本。

**Q3：充值後幾耐到帳？**

我試過信用卡即時到帳，支付寶就大約 1 至 2 分鐘。如果超過 10 分鐘都未見餘額，可以檢查付款紀錄或者聯絡客服。

**Q4：餘額可唔可以退款？**

以官方退款政策為準。一般來講，未使用嘅餘額退款手續比較繁複，所以建議按需充值，唔好一次過充太多。

**Q5：點樣知道 API 餘額不足？**

可以喺平台用量頁面睇，或者喺程式入面捕捉錯誤碼。常見嘅付款相關錯誤碼包括 402，具體以官方文檔為準。
