## 三步完成餘額查詢與充值

### 第一步：登入並查看餘額

用瀏覽器打開 platform.deepseek.com，登入後在左側選單點「Billing」或「帳單」。餘額以美元顯示，同時列出最近交易紀錄。我測試時發現，餘額更新有約 1 分鐘延遲；如果你剛剛充值完，重新整理頁面即可。

### 第二步：選擇充值金額

點擊「Top Up」按鈕，輸入金額（最低 10 美元）。系統支援信用卡（Visa/Mastercard）和支付寶（部分地區）。香港用戶用信用卡最直接，但要注意發卡銀行是否收取外幣交易費。

### 第三步：確認付款與查詢紀錄

付款成功後，餘額會自動更新。你可以用 API 的 `/user/balance` 端點查詢（需要 API key），或者直接在網頁後台查看。如果想自動化監控餘額，可以寫一個簡單的 cron job，每天呼叫一次餘額端點，低於某個閾值就發電郵提醒。這部分可以參考站內文章 [DeepSeek API Key 申請與限制解析](/posts/deepseek-api-key-and-limits/)，裡面有詳細的權限設定教學。

我實測了幾種方法，以下是最有效的三個：

1. **用虛擬銀行卡避開外幣手續費**：部分香港虛擬銀行（如眾安、Mox）提供免外幣交易費的 Visa 卡，變相節省 1%～2%。
2. **批量充值降低匯率波動**：如果每月用量穩定，一次過充值 50 美元比每次充 10 美元更划算，因為每次交易都可能被收取固定費用（視銀行而定）。
3. **監控用量避免浪費**：DeepSeek 的 API 定價以官方公佈為準，但你可以用 `max_tokens` 參數限制回覆長度，減少不必要的 token 消耗。關於 prompt 設計，可以參考 [DeepSeek Prompt 基礎教學](/posts/deepseek-prompt-basics/)，裡面有省 token 的技巧。

另外，如果你需要處理大量請求，記得設定重試機制，避免因網絡問題重複扣費。站內 [DeepSeek API 重試指南](/posts/deepseek-api-retry-guide/) 有詳細的 backoff 策略。
