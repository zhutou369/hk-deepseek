## 點解香港職場英文 Email 咁易出事

香港人寫英文 Email 好多時直接將廣東話句式譯過去，例如「Please kindly advise」連用、開頭用「Dear Sir/Madam」但內文又太過命令式。對方係外國客戶還好，如果係同亞太區同事溝通，語氣太硬會顯得冇禮貌，太軟又會被人覺得唔專業。

上週我幫一間中環中小企嘅市場部同事睇咗幾封對外 Email，發現最常見問題係「請求」同「催促」嘅界線模糊。例如想問進度，寫成「I want to know the status」，收件人睇落會似被質問。其實只要加一句「Could you share a quick update?」成件事就唔同晒。

DeepSeek 喺處理呢類語氣調整上幾好用，尤其係佢對上下文嘅理解比一般翻譯工具細緻。我用嘅係網頁版，型號係 DeepSeek-V3，2025 年 3 月實測有效。記住，模型版本同功能以官方文檔為準。

## 我實測嘅語氣調整流程（2025 年 3 月版）

我試過幾個唔同嘅 Prompt 寫法，發現最有效嘅唔係叫佢「幫我潤飾」，而係明確指出「寫給邊個、想達到咩效果、要避免咩語氣」。以下係我整理出嚟嘅三步流程，適用於大部分職場情境。

### 第一步：先定義收件人同場景

唔好一開始就貼段英文叫佢改。先寫一句背景，例如：「收件人係英國客戶，第一次合作，想催促報價但唔想顯得心急。」DeepSeek 會根據呢個設定調整用詞。如果係內部同事，可以寫「同 team 同事，想請求幫忙趕 deadline，語氣要客氣但直接」。

### 第二步：貼上原文，並標明「保留原意」

我習慣將原文放喺 Prompt 最尾，前面加一句「以下係我草擬嘅內容，請保留原意，只調整語氣同用詞」。咁樣可以避免佢改到偏離重點。如果原文有明顯文法錯誤，可以加「順便修正文法，但唔好改變句子結構」。

### 第三步：要求輸出對照版本

呢步好重要。我叫佢「用表格列出原句同建議句，並簡短解釋改動原因」。咁樣我就可以快速睇到邊啲位改咗，唔使成篇重新讀一次。實測發現，DeepSeek 喺解釋改動原因時會提到「被動語態顯得疏離」「過度使用驚嘆號降低專業感」等，對學習寫作都有幫助。

## 三個步驟搞掂語氣 Prompt

以下係我經常用嘅 Prompt 模板，你可以直接複製去 [DeepSeek 網頁版](https://chat.deepseek.com) 試。注意，如果你用 API，可以參考站內嘅 [API Key 與額度說明](/posts/deepseek-api-key-and-limits/)，避免爆 quota。

**步驟一：設定角色同場景**

```
你係一位香港職場英文導師，熟悉商業 Email 語氣。
收件人：美國客戶，合作超過兩年，關係友好。
場景：回覆對方查詢，想確認交貨日期但唔想顯得催逼。
```

**步驟二：貼上原文並加指示**

```
以下係我草擬嘅 Email，請保留原意，只調整語氣同用詞，令佢聽起來更自然、專業但唔生硬。

[貼上你的英文 Email]
```

**步驟三：要求對照輸出**

```
請用表格列出原句、建議句、改動原因。如果原句冇問題，可以標示「保持不變」。
```

我測試時發現，如果無指定「表格」，佢會用段落形式解釋，閱讀起嚟比較費時。另外，如果 Email 太長，建議分段貼，每次處理兩至三段，效果更穩定。

如果你對 Prompt 寫法有興趣，可以睇埋 [DeepSeek Prompt 基礎教學](/posts/deepseek-prompt-basics/)，入面有更多結構化指令嘅例子。

## 常見問題

**Q1：DeepSeek 會唔會改到偏離原意？**

有機會，尤其係原文比較精簡嘅時候。解決方法係喺 Prompt 加「保留原意」同「唔好添加新資訊」，並要求佢列出改動原因。我通常會快速對照一次，確認重要資訊（如日期、金額）冇被改動。

**Q2：免費版同 API 版輸出水準有冇分別？**

以我實測嚟講，網頁版同 API 版喺語氣調整任務上分別不大，但 API 版可以自訂 temperature 參數，適合需要穩定輸出嘅自動化流程。具體型號同定價以 [官方文檔](https://platform.deepseek.com) 為準。

**Q3：可唔可以叫佢直接寫一封全新 Email？**

可以，但建議你先提供要點（bullet points），再叫佢擴寫成 Email。如果直接叫佢「寫一封催交貨嘅 Email」，出嚟嘅內容會比較模板化，欠缺你公司嘅具體背景。

**Q4：如果對方係好senior嘅客，語氣要點調？**

喺 Prompt 寫明「收件人係 C-level，語氣要正式但唔好太卑微」，並要求避免使用縮寫（如 I'm、don't）。DeepSeek 會自動改用完整形式，同時減少感嘆號同表情符號。

**Q5：處理緊急 Email 時，有冇更快嘅方法？**

有，你可以預先寫好幾個場景嘅 Prompt 模板，儲存喺記事本。我自已會用 [Ollama 本地設置](/posts/deepseek-ollama-local-setup/) 離線跑一個細模型做快速潤飾，再喺網頁版覆核。不過本地模型嘅語氣細膩度始終不及線上版，建議只用作初步篩選。

最後提提你，如果 API 請求失敗，可以參考站內嘅 [重試指南](/posts/deepseek-api-retry-guide/)，入面有常見報錯碼嘅處理方法。希望呢篇教學幫到各位香港打工仔慳返啲改 Email 嘅時間。
