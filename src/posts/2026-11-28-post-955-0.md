## 一、卡顿实测：从 2025 年 7 月版本说起

上周升级到 Chrome 126 之后，我打开 DeepSeek 网页版（chat.deepseek.com）输入问题，光标闪了整整 10 秒才出字，滚动对话还会一卡一卡的。我机器是 16GB RAM 的 Windows 11 笔记本，网络用香港宽频 1000M，按理说不应该这样。

我先用开发者工具（F12）看 Network 面板，发现有几个 JS 文件加载时间超过 3 秒，而且 Response Headers 显示 `cache-control: max-age=0`，意思是浏览器每次都重新下载。这现象通常跟缓存失效或者扩展拦截有关。

![DeepSeek 网页版开发者工具网络面板截图](/static/images/photo-1488590528505-98d2b5aba04b.jpg)

如果你也遇到类似情况，可以跟着下面三步排查。记住，以下操作只基于浏览器和网络设置，不会改动 DeepSeek 账户或者 API 额度。

## 二、第一步：清除浏览器缓存（以 Chrome 为例）

1. 按键盘 `Ctrl + Shift + Delete`（Mac 用 `Cmd + Shift + Delete`），打开“清除浏览数据”窗口。
2. 时间范围选“所有时间”，勾选“缓存图片和文件”和“Cookie 及其他网站数据”。注意：清除 Cookie 会登出 DeepSeek，请先记下登录方式。
3. 点“清除数据”，等 10 秒左右完成。之后重新打开 chat.deepseek.com，强制重新加载（`Ctrl + F5`）。

我测试时发现，单单清缓存已经让首屏加载时间从 8 秒降到 4 秒。如果还有卡顿，就得看第二步。

另外，如果你之前改过 DNS 或者用过 VPN，建议先还原默认设置。有读者问过我为什么登录不上，可以参考站内的[网页版登录疑难排解](/posts/deepseek-web-login-troubleshoot/)，里面有讲证书和地区限制的检查方法。

## 三、第二步：逐个停用扩展找出元凶

扩展是最常见的卡顿来源，尤其是广告拦截、翻译、密码管理还有 AI 摘要类。我的做法是：

1. 在 Chrome 地址栏输入 `chrome://extensions/`，进入扩展管理页。
2. 先全部关闭（拨走蓝色开关），然后逐个开回来，每开一个就 refresh DeepSeek 页面，看哪个让加载变慢。
3. 重点留意有没有扩展要求“读取及变更所有网站数据”，这类权限很容易跟 DeepSeek 的 websocket 连接冲突。

我自己的实测结果：一个知名翻译扩展会把页面文字逐句送去翻译 API，导致 DOM 频繁变动，CPU 占用率飙到 70%。停用之后，滚动顺畅回来了。

![浏览器扩展管理页面示意图](/static/images/photo-1451187580459-43490279c0fa.jpg)

如果你想用本地模型减轻网页版负担，可以看[Ollama 本地部署教学](/posts/deepseek-ollama-local-setup/)，把部分查询转去自己电脑跑，不用老是等网页回应。

## 四、第三步：检查网络与 DNS 设置

如果清完缓存、停完扩展还卡，就要看网络。以下是我常用的快速检查：

- 打开命令提示符，输入 `ping chat.deepseek.com`，看平均延迟。香港本地通常 20-50ms，如果超过 150ms 就可能是路由问题。
- 转用公共 DNS，比如 `1.1.1.1` 或 `8.8.8.8`，有时 ISP 的 DNS 解析慢会拖累首次连接。
- 检查浏览器是不是开了“节省数据”模式（Chrome 设置 → 性能 → 内存节省功能），这个模式会冻结后台标签页，但有时会误判 DeepSeek 页面。

我上周就是因为开了内存节省功能，切换标签页回去 DeepSeek 时要重新加载，感觉好像卡顿。关闭之后就没事。

## 五、常见问题

**Q1：清除缓存会不会删除我的对话记录？**

不会。对话记录主要存在 DeepSeek 服务器，清除浏览器缓存只影响本地暂存文件。但如果你用“无痕模式”，关闭窗口后记录就没了。

**Q2：为什么我只用 DeepSeek 网页版，但有时回复很慢？**

网页版速度受服务器负载和网络影响。如果只是个别时段慢，可能是高峰期的正常现象。你可以试试用 API 搭配重试机制，站内有[API 重试指南](/posts/deepseek-api-retry-guide/)可以参考。

**Q3：停用扩展之后，网站功能不正常怎么办？**

逐个开回来，找出冲突的那个，然后在该扩展的设置里把 `chat.deepseek.com` 加入白名单（允许清单）。

**Q4：有没有说哪个浏览器最顺？**

我实测 Chrome 126 和 Edge 126 表现接近，Firefox 128 就有点滞后。建议用最新版本，并且关闭不用的标签页。以官方文档为准，他们没指定浏览器。

**Q5：怎么知道是不是 DeepSeek 服务器问题？**

可以看官方状态页（如果有）或者去社区问问其他用户。如果个个都说慢，就不关你机器事。

最后提醒你，如果经常要用提示词，可以看[提示词基础教学](/posts/deepseek-prompt-basics/)，写得精准一点，减少来回对话次数，间接减轻卡顿感觉。
