## 三步實踐：搭建你的離線語音助手

好啦，準備好了沒？現在就來手把手搭起你的專屬語音助手！

### 第一步：搞定本地語音轉文字（STT）和文字轉語音（TTS）

首先，咱得讓電腦能聽懂人話（語音轉文字），還能開口說話（文字轉語音）。

1.  **安裝 Whisper**：
    打開你的終端機或命令提示字元，敲入這行指令：
    ```bash
    pip install 'whisper-timestamped==1.1.2' sounddevice numpy
    ```
    我測試時發現 `whisper-timestamped` 在處理實時語音時效果更好，版本 `1.1.2` 穩定性不錯。`sounddevice` 用來錄音，`numpy` 嘛，就是個必須的「小跟班」。

2.  **實現 STT 錄音與轉寫**：
    這塊兒主要是麥克風的事兒。下面是個簡單的 Python 骨架，幫你錄音，再用 Whisper 轉成文字：

    ```python
    import whisper_timestamped as whisper
    import sounddevice as sd
    import numpy as np
    import wave
    
    # 加載 Whisper 模型（可選擇 small, medium, large 等模型）
    # small 模型在本地運行速度快，但準確度略遜於 large。
    model = whisper.load_model("small")
    
    def record_audio(duration=5, samplerate=16000):
        print("錄音中...")
        audio = sd.rec(int(duration * samplerate), samplerate=samplerate, channels=1, dtype='int16')
        sd.wait() # 等待錄音完成
        print("錄音結束。")
        return audio
    
    def transcribe_audio(audio_data, samplerate=16000):
        # 將 int16 數據轉換為 float32，Whisper 需要此格式
        audio_float32 = audio_data.astype(np.float32) / 32768.0
        
        # 轉寫
        result = model.transcribe(audio_float32, language="zh") # 指定語言為中文
        return result["text"]
    
    # 示例用法
    # recorded_audio = record_audio(duration=8) # 錄音8秒
    # text = transcribe_audio(recorded_audio)
    # print(f"你說了: {text}")
    ```

3.  **實現本地文字轉語音（TTS）**：
    要實現完全離線的 TTS，`pyttsx3` 是個不錯的跨平台選項。它直接利用系統內建的語音引擎，不用聯網。

    ```bash
    pip install pyttsx3
    ```

    ```python
    import pyttsx3
    
    def speak(text):
        engine = pyttsx3.init()
        engine.say(text)
        engine.runAndWait()
    
    # 示例用法
    # speak("你好，我是您的 DeepSeek 離線助手。")
    ```

### 第二步：部署本地大語言模型（LLM）與對接 DeepSeek

接下來，我們要讓助手擁有思考和回覆的能力。這一步會用到 Ollama 和 DeepSeek 的智能。

1.  **運行 Ollama LLM**：
    如果你已安裝 Ollama，並下載了 `llama3` 模型，現在就可以透過它的 API 進行交互。Ollama 預設在 `http://localhost:11434` 啟動 API 服務。我們的 [本地運行 Ollama 基礎教學](/posts/deepseek-ollama-local-setup/) 文章有更詳細的安裝與使用說明。

2.  **與 Ollama API 交互**：
    安裝 `ollama` Python 庫：`pip install ollama`。

    ```python
    import ollama
    
    def get_ollama_response(prompt, model_name="llama3"):
        response = ollama.chat(model=model_name, messages=[{'role': 'user', 'content': prompt}])
        return response['message']['content']
    
    # 示例用法
    # ollama_answer = get_ollama_response("香港有多少人口？")
    # print(f"Ollama 回覆: {ollama_answer}")
    ```

3.  **集成 DeepSeek API 作為高級智能（可選）**：
    當你需要更強大的推理能力或處理更專業、更長的內容時，可以選擇性地調用 DeepSeek API。這當然需要網絡連接，但能顯著提升助手的「智商」！

    安裝 `openai` 庫（DeepSeek API 兼容 OpenAI API 格式）：`pip install openai`。

    ```python
    from openai import OpenAI
    
    # 請替換為您的 DeepSeek API Key
    DEEPSEEK_API_KEY = "YOUR_DEEPSEEK_API_KEY"
    
    deepseek_client = OpenAI(api_key=DEEPSEEK_API_KEY, base_url="https://api.deepseek.com/v1")
    
    def get_deepseek_response(prompt, model_name="deepseek-chat"):
        try:
            response = deepseek_client.chat.completions.create(
                model=model_name,
                messages=[{"role": "user", "content": prompt}]
            )
            return response.choices[0].message.content
        except Exception as e:
            print(f"DeepSeek API 錯誤: {e}")
            return "抱歉，DeepSeek 暫時無法回覆。"
    
    # 示例用法
    # deepseek_answer = get_deepseek_response("詳細解釋量子糾纏的物理概念和應用前景。")
    # print(f"DeepSeek 回覆: {deepseek_answer}")
    ```
    透過 DeepSeek API，我們還可以對本地 Ollama 模型進行 [提示詞優化](/posts/deepseek-prompt-basics/)，讓它在本地運行時表現更好。

### 第三步：構建交互邏輯與閉環

最後一步是把所有組件整合起來，形成一個流暢的語音交互循環。

```python
import time

def main_loop():
    print("DeepSeek 離線語音助手已準備就緒，請說話。說'再見'結束對話。")
    conversation_history = []
    
    while True:
        # 1. 錄音並轉寫
        audio_data = record_audio(duration=5) # 錄音5秒
        user_text = transcribe_audio(audio_data)
        print(f"你說了: {user_text}")
        
        if "再見" in user_text.lower():
            speak("再見！期待下次為您服務。")
            break
        
        if not user_text.strip():
            speak("我沒聽清楚，請再說一次。")
            continue
            
        conversation_history.append({"role": "user", "content": user_text})
        
        # 2. 判斷使用 Ollama 還是 DeepSeek（嘿嘿，這裡可以加入更多邏輯）
        # 簡單判斷：如果網絡可用且問題複雜，則使用 DeepSeek；否則使用 Ollama
        # 實踐中可能需要更精細的判斷，例如關鍵詞觸發、問題長度等
        response_text = ""
        if "高級" in user_text or len(user_text) > 50: # 簡單判斷，可自行優化
            print("正在調用 DeepSeek 高級智能...")
            response_text = get_deepseek_response(user_text)
        else:
            print("正在調用本地 Ollama 模型...")
            response_text = get_ollama_response(user_text)
            
        print(f"助手回覆: {response_text}")
        conversation_history.append({"role": "assistant", "content": response_text})
        
        # 3. 語音輸出回覆
        speak(response_text)
        time.sleep(1) # 稍作停頓

# 在腳本的入口處調用 main_loop()
# if __name__ == "__main__":
#     main_loop()
```

這段代碼提供了一個基礎框架。你可以根據自己喜好，加更多功能，比如讓它記住上下文、搞多輪對話，或者設定一些特定任務的觸發詞啥的。透過 `conversation_history` 列表，我們可以把之前的對話傳給 LLM，讓它更好地理解語境。

## 常見問題

### Q1: 搭建這樣的系統需要很強的顯示卡嗎？

**A:** 其實不一定啦！Whisper 的 `small` 模型對顯示卡要求不高，純 CPU 都能跑得動。Ollama 跑像 `llama3:8b` 這種小模型時，沒顯示卡的話 CPU 也行，不過速度肯定會慢不少。但如果你的電腦有 NVIDIA 顯示卡，而且 VRAM 夠多（比如 8GB+），那運行速度絕對能給你驚喜！對於香港中小企來說，搞台配備入門級顯示卡的工作站，就能有很不錯的體驗了。

### Q2: 我的對話內容會被 DeepSeek 或其他服務提供商知道嗎？

**A:** 完全不用擔心會上傳！用 Whisper 和 Ollama 做的語音轉文字和本地模型推理，數據全程都在你電腦裡處理，不會跑出去。只有在你特意想用 DeepSeek API 處理那些燒腦問題時，相關的查詢內容才會傳輸到 DeepSeek 的伺服器。啥時候用 DeepSeek API，完全是你自己說了算，數據隱私掌握在你手上！

### Q3: 這個離線助手可以用來做什麼實際應用？

**A:** 應用範圍廣著呢！比如你可以把它當成：

*   **個人知識庫助手**：想查本地文檔或筆記？直接說，馬上給你答案。
*   **內部培訓小幫手**：給員工搞個語音互動問答，培訓效果槓槓的！
*   **香港中小企辦公室助理**：處理內部日程、匯報數據這些小事，再也不用擔心機密洩露了。
*   **寫代碼的好夥伴**：邊寫邊問編程問題，Ollama 或 DeepSeek 馬上給你建議，效率飆升！
