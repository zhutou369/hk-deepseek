## 點解要比較呢兩個免費版？

上個月（2025 年 3 月）我幫一間香港中小企做內部培訓，佢哋想用免費 AI 工具輔助寫產品描述同簡單 script。老闆問我：「DeepSeek 免費版同 ChatGPT 免費版，邊個抵用？」我唔想靠感覺答，於是就用同一組 prompt 做咗個實測。

測試日期：2025 年 3 月 15 日至 20 日。DeepSeek 用網頁版（chat.deepseek.com），模型顯示為 V3；ChatGPT 用免費版（GPT-3.5）。兩邊都係乾淨對話，冇開任何外掛。

## 實測步驟：我點樣做對比

我準備咗 5 條中文寫作 prompt 同 5 條程式 prompt，全部用香港繁體中文寫，唔加入任何提示詞技巧，模擬普通用戶直接問。

**步驟一：固定測試環境**

用同一部 laptop、同一個瀏覽器（Chrome 無痕模式），每次測試前登出再登入，確保冇殘留對話影響。

**步驟二：逐條 prompt 輸入並記錄**

中文寫作 prompt 包括：寫一封投訴信、改寫一段產品描述、作一個 IG 帖文、總結一篇新聞、寫一個活動宣傳句。程式 prompt 包括：寫一個 Python 函數計折扣、寫一個 JavaScript 表單驗證、解釋一段 SQL、寫一個 bash script 備份檔案、除錯一段 Python 報錯。

**步驟三：用同一標準評分**

我按三個維度打分（1-5 分）：準確度、流暢度、可執行性。中文寫作側重前兩項，程式侧重後兩項。評分時我盡量唔睇品牌，只看輸出。

如果你想自己試，可以直接去 [DeepSeek 網頁版](https://chat.deepseek.com) 開個免費帳號，或者參考我之前寫嘅 [DeepSeek 提示詞基礎教學](/posts/deepseek-prompt-basics/)，入門會快啲。

## 中文寫作：邊個更似人講嘢？

我測試時發現，DeepSeek 嘅中文輸出明顯較少「翻譯腔」。例如叫佢寫投訴信，ChatGPT 免費版會用「敬啟者」開頭，但全篇結構好工整，似範文；DeepSeek 會用「你好，我係住喺將軍澳嘅陳先生」呢種口語開頭，再逐步講問題。對於香港用戶，後者更自然。

不過要留意，DeepSeek 有時會過度口語化，例如寫正式郵件時用咗「唔該晒」呢類字眼。我測試時要手動改一兩句。ChatGPT 免費版嘅中文就穩陣啲，但創意度低，作 IG 帖文時來來去去都係「立即選購」呢類句式。

|------|-------------|----------------|

| 流暢度 | 5 | 3 |
| 香港語感 | 4 | 3 |

## 程式能力：邊個少啲低級錯誤？

程式方面，我測試時發現差距較明顯。叫兩邊寫一個 Python 函數計折扣，ChatGPT 免費版一次過俾咗正確答案，但冇處理負數輸入；DeepSeek 版本就加咗 `if discount < 0` 嘅檢查，仲寫咗簡單註解。

不過，當我要求寫一個 JavaScript 表單驗證時，DeepSeek 第一次輸出用咗 `var` 而唔係 `let`，仲漏咗一個分號，喺瀏覽器 console 報 `Uncaught SyntaxError`。我追問之後佢改正咗。ChatGPT 免費版就一次過搞掂，但代碼風格較舊。

除錯測試最有趣：我俾咗一段有 `KeyError` 嘅 Python 代碼，DeepSeek 唔止指出錯誤，仲解釋咗 dict 取值嘅正確做法；ChatGPT 免費版只係話「找不到鍵」，冇建議 `get()` 方法。

如果你打算用 DeepSeek 寫程式，建議先睇吓 [API 重試機制指南](/posts/deepseek-api-retry-guide/)，因為免費版有時會出錯，識得重試會穩定啲。

## 常見問題

**1. DeepSeek 免費版有冇限制？**

有。根據公開資訊，免費版有每日對話次數限制，高峯時段可能要排隊。具體數字以官方文檔為準。

**2. 我唔想用網頁版，可以本地跑嗎？**

可以，用 Ollama 就得。我寫過一篇 [DeepSeek Ollama 本地安裝教學](/posts/deepseek-ollama-local-setup/)，跟住做大概 20 分鐘搞掂。不過本地版要睇你張顯示卡，太舊嘅話會好慢。

**3. 兩個免費版邊個適合寫中文文案？**

如果你要香港地道語氣，DeepSeek 較好；如果要正式書面語，ChatGPT 免費版穩陣啲。我測試時會兩邊一齊用，取長補短。

**4. 用免費版處理公司數據安全嗎？**

免費版對話內容有機會被用嚟改進模型，建議唔好輸入客戶個人資料或公司機密。如果係中小企內部使用，可以考慮用 API 加自己嘅 RAG 系統，減少風險。

**5. 點解有時 DeepSeek 回覆好慢？**

高峯時段伺服器負載高，尤其係晚上。我測試時下晝反應快過夜晚。如果趕時間，可以試吓轉用 API，或者睇吓 [Web 登入疑難排解](/posts/deepseek-web-login-troubleshoot/) 睇吓係咪網絡問題。
