## 點解要揀 SDK？

上個月有個做中小企嘅朋友問我：「喂，我想用 DeepSeek 個 API 嚟寫個客服機械人，但係見到有 openai-python、openai-node 同官方 SDK，究竟有咩分別？」我當下答唔出，因為我平時主力用 Python，但佢個項目係 Node.js。於是的起心肝，喺 2025 年 3 月頭用咗幾晚時間，將三個 SDK 都裝一次、跑一次，順便記錄低報錯碼同實際體驗。

先講結論：如果你本身已經用開 OpenAI 嘅 library，轉過嚟 DeepSeek 幾乎零成本；但如果你想要最新功能或者原生支援，就要留意官方 SDK 嘅更新節奏。以下係我嘅實測分享。

## 三個 SDK 基本介紹

**openai-python**：呢個係 OpenAI 官方嘅 Python library，版本 1.30.0 或以上已經可以直接改 `base_url` 去指向 DeepSeek 嘅 API endpoint。好處係社群大、文件多，你搵到嘅教學九成都可以照搬。

**openai-node**：同樣係 OpenAI 出品，Node.js 版本。我測試嗰陣用咗 4.52.0，都係改 `baseURL` 就得。對於前端或全棧開發者嚟講，呢個係最順手嘅選擇。

**DeepSeek 官方 SDK**：目前官方有提供 Python 同 Node.js 嘅封裝，但更新頻率唔算好高。我裝嗰陣係 0.1.2 版，功能上同 openai-python 分別不大，但少咗一啲 OpenAI 生態嘅工具鏈支援。如果你項目好依賴 LangChain 或者 LlamaIndex，用 openai-python 會少啲頭痛。

有一點要留意：無論用邊個 SDK，你都要先喺 [DeepSeek 平台](https://platform.deepseek.com) 申請 API key。我第一次申請時唔為意有免費額度，結果搞咗一輪先發現要實名認證。詳細步驟可以參考我之前寫嘅 [API Key 申請同限額教學](/posts/deepseek-api-key-and-limits/)。

## 實測步驟同注意事項

我嘅測試環境係 macOS Sonoma，Python 3.12，Node.js 20.11。以下係我實際行過嘅三步：

**第一步：安裝套件**
Python 用 `pip install openai==1.30.0`，Node 用 `npm install openai@4.52.0`。如果你想試官方 SDK，就 `pip install deepseek-sdk`（以官方文檔為準）。

**第二步：設定 base_url 同 API key**
Python 範例：
```python
from openai import OpenAI
client = OpenAI(api_key="你的key", base_url="https://api.deepseek.com")
```
Node 範例：
```javascript
import OpenAI from 'openai';
const client = new OpenAI({ apiKey: '你的key', baseURL: 'https://api.deepseek.com' });
```
記得唔好將 key 硬編碼入 code，用環境變數好啲。

**第三步：發送第一個請求**
我用咗最簡單嘅 chat completion，model 填 `deepseek-chat`。三個 SDK 都順利回傳結果，但 openai-node 喺串流模式（stream）下，我遇到一次 `429 Too Many Requests`，後來發現係我冇設定 retry 邏輯。如果你都會用串流，建議睇睇 [API 重試機制指南](/posts/deepseek-api-retry-guide/)，入面有教點樣加 exponential backoff。

另外，我測試時發現官方 SDK 嘅錯誤訊息比較簡潔，有時只回傳一個 code，唔似 openai-python 咁會包埋多啲 context。呢點對於 debug 嚟講有少少不便，但如果你淨係要基本功能，其實影響不大。

## 常見問題

**Q1：用 openai-python 會唔會俾 DeepSeek 封鎖？**
唔會。DeepSeek 官方文件明確認可呢種用法，只要 `base_url` 設定正確就得。

**Q2：官方 SDK 有冇獨家功能？**
暫時未見有。以我測試嘅 0.1.2 版為例，功能同 openai-python 重疊，但社群支援較少。

**Q3：我個項目用 TypeScript，應該揀邊個？**
openai-node 嘅型別定義最齊全，官方 SDK 嘅 TypeScript 支援仲係基本。如果你好睇重型別安全，openai-node 會好啲。

**Q4：三個 SDK 嘅定價有冇分別？**
SDK 本身免費，你只需要俾 API 使用費。DeepSeek 嘅定價以官方公佈為準，暫時未見 SDK 會影響收費。

**Q5：如果我想本地跑模型，SDK 關唔關事？**
如果你用 Ollama 本地部署，可以直接用 OpenAI 兼容接口，唔一定要用 DeepSeek SDK。可以參考 [Ollama 本地設定教學](/posts/deepseek-ollama-local-setup/)。

最後提提大家，如果你嘅應用涉及敏感數據，記得睇清楚 [數據安全同 prompt 設計要點](/posts/deepseek-prompt-basics/)，始終 API 係將資料送去第三方伺服器，自己衡量風險。
