## 第二步：建立財報分析提示詞（Prompt）

**Prompt 寫得好唔好，直接決定 DeepSeek 夠唔夠力！** 一個精準 Prompt 令 DeepSeek 準確抽到你想要嘅嘢。好似財報分析，我哋想佢從年報拎關鍵數據同亮點。睇吓呢個示範：

```
請你扮演一位經驗豐富嘅財經分析師。我會提供一份上市公司嘅最新年報內容。請你從中抽取以下關鍵資訊，並以 JSON 格式輸出：

1. 公司名稱
2. 報告期（例如：2023 財政年度）
3. 總營收（請提供具體數字及貨幣單位）
4. 淨利潤（請提供具體數字及貨幣單位）
5. 每股盈利（EPS，請提供具體數字）
6. 毛利率（百分比）
7. 負債比率（總負債/總資產，百分比）
8. 本報告期內公司業務嘅主要亮點或挑戰（100字以內摘要）

如果某項資訊未能喺報告中找到，請以「N/A」表示。

以下係年報內容：
[喺呢度貼上年報嘅相關文本內容]
```

## 第三步：分析新聞情緒因子

新聞情緒對短期股價影響超大！我哋可以用 Prompt 叫 DeepSeek 分析新聞內容情緒：

```
請你扮演一位市場情緒分析師。我會提供一篇財經新聞報導。請你判斷呢篇報導對相關公司或行業嘅情緒影響，並以 JSON 格式輸出：

1. 新聞標題
2. 相關公司或行業（如果明確）
3. 情緒判斷（請喺「正面」、「負面」或「中性」中選擇一個）
4. 情緒強度（請喺 1 到 5 之間評分，1 為極弱，5 為極強）
5. 判斷依據摘要（50字以內說明主要原因）

以下係新聞報導內容：
[喺呢度貼上新聞報導內容]
```

搞大量新聞時，要記得 DeepSeek API 請求限制同錯誤重試。睇熟呢份 [DeepSeek API 嘅重試指南](/posts/deepseek-api-retry-guide/)，包你自動化系統穩如泰山。DeepSeek 俾完分數，就將佢塞入量化模型，當係個新因子考慮。例如，隻股一有勁多負面新聞，模型可能即刻叫你賣出！

## 常見問題

*   **DeepSeek 分析結果準唔準㗎？**
    準唔準睇你 Prompt 寫得點，同埋原始數據靚唔靚。**我親身試過，不斷試、不斷執 Prompt，再加多啲背景資料，準確度真係會高好多！** 重要決定建議都係人手 Double Check 下 DeepSeek 嘅結果，尤其係啲模棱兩可嘅內容。記住，佢只係輔助工具，唔係神仙。

*   **用 DeepSeek API 點計錢㗎？**
    DeepSeek API 通常按 Token 量收費，即係你輸入同輸出嘅字數。大規模用之前，最好睇清楚 DeepSeek 嘅 [平台定價](https://platform.deepseek.com/pricing)，順便設個預算上限。Prompt 優化得好，可以省唔少 Token，幫你慳錢！

*   **點樣搞掂海量數據同實時更新？**
    海量數據要搭條穩陣嘅數據管道（Data Pipeline），包晒收集、清洗、傳輸同 call API。可以用消息隊列（Message Queue），好似 RabbitMQ 或 Kafka，嚟管理請求，確保 API 高併發時都唔會冧機。實時更新呢，可以設個定時任務（Cron Job）或者事件驅動（Event-driven）系統，一有新數據或新聞，即刻開 DeepSeek 做分析！
