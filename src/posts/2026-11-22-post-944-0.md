## 斷網前要做嘅三件事

![DeepSeek 離線部署前檢查網絡與顯示卡設定](/static/images/photo-1581091226825-a6a2a5aee158.jpg)

**第一步：確認模型完整下載。** 趁仲有網，用 `ollama pull deepseek-r1:14b` 拉落嚟。想細啲嘅話 7B 或 8B 都支援，但 14B 喺 8GB 顯示卡機器上跑得比較順。拉完用 `ollama list` 睇下，檔案大小正常就代表下載完整。

**第二步：閂晒所有會自動連網嘅背景服務。** 包括 Ollama 自己嘅更新檢查（可以設環境變數 `OLLAMA_NOPRUNE=1` 避免自動清理，但更新檢查就要靠防火牆擋）。我用最土炮嘅方法：直接喺路由器封鎖嗰部機嘅 MAC 地址，模擬真實斷網。

**第三步：準備離線更新用嘅 USB 或內網共享資料夾。** 斷網之後冇得叫模型自己上網 download 新版本，所以要預先喺其他有網機器下載好模型檔案，再搬過去。呢部分下面詳細講。

## 離線實測：中英夾雜照答

![DeepSeek 模型在無網絡環境下回答香港用家提問](/static/images/photo-1520607162513-77705c0f0d4a.jpg)

我測試時用咗個簡單提示詞：「用香港繁體中文解釋咩係區塊鏈，唔該。」斷網狀態下，模型照樣俾出流暢答案，冇彈任何需要聯網嘅錯誤。推論速度方面，14B 版本喺 RTX 3060 上大約每秒 18 個 token，用嚟做內部文件摘要或者客服草稿絕對夠用。

有一點要留意：第一次載入模型嗰陣，Ollama 會嘗試檢查遠端有冇更新，斷網嘅話佢會等幾秒然後報個 timeout 警告，但唔影響運行。你可以在啟動參數加 `--no-update-check` 跳過呢個檢查（以官方文檔為準，唔同版本參數可能略有差異）。

另外我試過用 `curl` 直接呼叫本地 API 端點 `http://localhost:11434/api/generate`，斷網下完全正常，即係你可以將 DeepSeek 嵌入內部表單系統或者 Excel 巨集，唔需要對外連線。

## 手動更新模型權重步驟

斷網環境最麻煩就係更新。以下係我實測可行嘅流程，適用於 Ollama 管理嘅模型（以 2025 年 3 月 1 日嘅 Ollama 0.5.7 為例）：

1. **喺有網機器下載新模型**：用 `ollama pull deepseek-r1:14b` 拉最新版本，然後去 `~/.ollama/models/blobs/` 資料夾，複製對應嘅 blob 檔案出嚟。你可以用 `ollama show deepseek-r1:14b --modelfile` 核對檔案雜湊值。
2. **將 blob 檔搬去離線機**：用 USB 或者內網 SMB 共享，複製 blob 檔到離線機同一路徑。權限不足記得用 `chmod` 調整。
3. **重建模型並驗證**：喺離線機執行 `ollama create deepseek-r1:14b -f ./Modelfile`，Modelfile 可以從有網機器匯出。完成後用 `ollama run deepseek-r1:14b` 測試，確認回答正常。

想輕量啲嘅方案，可以參考我哋之前寫嘅 [DeepSeek Ollama 本地安裝教學](/posts/deepseek-ollama-local-setup/)，入面有講點精簡模型檔案。仲有，更新之後記得重新檢視你嘅 [提示詞基本結構](/posts/deepseek-prompt-basics/)，因為新版本有時對指令格式更敏感。

## 常見問題

**Q1：斷網之後，模型會唔會偷偷連去邊度？**

以我測試嘅 Ollama 版本為例，佢只會連 localhost 嘅 API 端口，唔會對外通訊。但如果你用其他推論框架，建議用 `netstat` 或者防火牆規則確認一下。

**Q2：離線環境可以微調模型嗎？**

可以，但你要預先下載好訓練資料同相關套件。不過對一般中小企嚟講，直接用預訓練模型加上好嘅提示詞已經夠用，微調成本效益唔高。

**Q3：更新模型一定要成個檔案搬？有冇得只更新部分？**

Ollama 嘅模型以 blob 為單位，通常更新都係整組替換，因為權重檔案係完整二進位檔。如果只想更新 tokenizer 或者設定檔，可以只換 Modelfile，但權重還是要重新拉。

**Q4：斷網環境下，API 呼叫會唔會出錯？**

只要你的應用程式指向 `http://localhost:11434` 就冇問題。我試過用 Python 嘅 requests 庫直接 call，完全正常。要留意嘅係 error code 如果出現 `connection refused`，通常代表 Ollama 服務未啟動，唔關斷網事。

**Q5：香港中小企用邊張顯示卡最抵？**

以 14B 模型嚟講，RTX 3060 12GB 或者 RTX 4060 Ti 16GB 都夠跑。如果你要跑 32B 或以上，就要考慮 RTX 4090 或者用 CPU 加記憶體硬扛，但速度會慢好多。

## 我嘅小結

斷網用 DeepSeek 絕對可行，關鍵係預先規劃好更新流程。我而家每季會手動更新一次模型，順便檢查 [API 重試機制](/posts/deepseek-api-retry-guide/) 嘅設定有冇要調整。如果你只需要基本問答，其實 7B 版本已經好夠用，唔使追最新。

最後提提你：如果你日後想駁返上網用官方 API，記得先睇清楚 [API Key 與用量限制](/posts/deepseek-api-key-and-limits/)，免得斷網太耐忘記咗點設定。
