## 點解要開兩步驟驗證？

上個月我有個朋友喺網吧登入完 DeepSeek，隔幾日就發現對話紀錄被清空，仲有人用佢個帳號試探 API 額度。雖然最後冇金錢損失，但已經嚇到佢即刻改密碼。呢類情況其實開咗兩步驟驗證（2FA）就可以擋住大部分撞密碼攻擊，尤其係我哋呢啲成日喺唔同 device 登入嘅用家。

## 實測版本與前提

我上週升級咗 DeepSeek 網頁版（2025 年 6 月介面），實測咗兩步驟驗證嘅完整流程。開始之前，你需要：

- 一個已綁定電郵或手機嘅 DeepSeek 帳號
- 一部手機（用嚟裝驗證器 App，例如 Google Authenticator 或 Microsoft Authenticator）
- 穩定網絡（我試過用香港寬頻同 csl 都冇問題）

如果你仲未搞得掂登入問題，可以參考站內嘅 [DeepSeek 網頁版登入疑難排解](/posts/deepseek-web-login-troubleshoot/)，入面有講點樣處理驗證碼收唔到嘅情況。

## 三步設定流程

### 第一步：入安全設定搵 2FA 選項

登入 DeepSeek 網頁版後，撳右上角頭像，揀「設定」>「帳號安全」。喺「兩步驟驗證」一欄撳「開啟」。我測試時發現，如果你之前未綁定手機，系統會先要求你驗證一次電郵或手機，確保係本人操作。

### 第二步：掃 QR Code 綁定驗證器

跟住畫面會顯示一個 QR Code，用手機驗證器 App 掃描。掃完之後，App 會顯示一組 6 位數驗證碼，喺網頁輸入確認。呢一步要留意：QR Code 有時效，我試過等咗兩分鐘先掃，結果要重新整理頁面再嚟過，所以建議一見到就即刻掃。

![DeepSeek 兩步驟驗證 QR Code 綁定畫面](/static/images/photo-1600132806370-bf17e65e942f.jpg)

### 第三步：保存備用碼並測試登入

設定成功後，系統會俾你 10 組備用碼。呢啲碼一定要抄低或者影相保存，因為將來如果冇咗手機，就要靠佢哋嚟登入。我習慣將備用碼放喺密碼管理器（例如 Bitwarden），唔好淨係存喺手機。最後，登出再登入一次，確認系統有要求你輸入驗證碼，咁就代表設定完成。

## 常見問題

**Q1：驗證器 App 顯示嘅驗證碼一直錯誤，點算？**

好大機會係手機時間唔準。去手機設定將「自動設定時間」開啟，或者手動校準時間，通常就解決。如果仲係唔得，試下刪除再重新掃 QR Code 綁定。

**Q2：我唔見咗手機，又冇備用碼，點算？**

呢個情況比較麻煩，你需要用註冊電郵聯絡 DeepSeek 支援團隊，提供帳號相關資訊嚟驗證身份。實際處理時間以官方回覆為準。所以強烈建議大家一定要保存備用碼。

**Q3：兩步驟驗證會唔會影響 API 調用？**

唔會。2FA 主要係保護網頁登入同帳號操作，API key 嘅調用係另一套機制。如果你用 API 遇到限流問題，可以睇 [DeepSeek API 密鑰與限額說明](/posts/deepseek-api-key-and-limits/)，入面有講點樣檢查用量。

**Q4：公司同事多人共用一個帳號，開 2FA 會唔會好麻煩？**

確實會。如果係團隊共用，建議考慮用 Ollama 做本地部署，或者申請多個子帳號。我呢排都試緊 [DeepSeek Ollama 本地安裝步驟](/posts/deepseek-ollama-local-setup/)，將部分模型放喺公司內部網絡行，減少對外依赖。

**Q5：開啟 2FA 之後，仲有咩要留意？**

記得定期檢查帳號嘅登入記錄，同埋唔好喺公共電腦勾選「記住我」。另外，如果你有用提示詞做自動化流程，可以參考 [DeepSeek 提示詞基礎教學](/posts/deepseek-prompt-basics/) 入面嘅安全建議，避免將敏感資料直接貼入對話。

## 少少個人心得

我測試時發現，DeepSeek 嘅 2FA 設定流程算直觀，但備用碼嘅提示唔夠明顯，好容易順手關咗個視窗就唔記得保存。建議大家設定完之後，即刻將備用碼匯入密碼管理器，或者列印出嚟放喺安全地方。

另外，如果你係香港中小企老闆，想將 DeepSeek 用喺內部文件處理，記得同 IT 同事夾清楚邊個負責管理 2FA 裝置，避免離職同事仲有權限。想知更多帳號安全設定，可以去 [platform.deepseek.com](https://platform.deepseek.com) 睇官方說明（以官方文檔為準）。

最後，2FA 只係其中一層防護，平時保持密碼強度同埋唔好亂撳不明連結，先係最根本嘅做法。希望呢篇教學幫到大家。
