## 點解會咁？

上個禮拜我用 DeepSeek 幫手整理一份香港客戶嘅會議紀錄，開頭明明寫明「請用繁體中文輸出」，頭兩段都正常，但去到第三段就開始出現「软件」「网络」呢類簡體字。初時以為係偶發，但連續試咗五次，有三次都係咁。

後來我翻查 [DeepSeek 官方 API 文檔](https://platform.deepseek.com) 嘅參數說明，發現語言輸出主要靠 prompt 約束，模型本身冇一個「強制繁體」嘅開關。換句話說，你要喺 prompt 入面講清楚，而且要用對方法講。

## 我嘅實測環境同版本

我係用 DeepSeek-V3 模型，透過 API 調用，日期係 2025 年 3 月 12 日。客戶端係香港寬頻 1000M 家居網絡，冇用 VPN。測試時 temperature 設 0.7，max_tokens 設 2048。如果你用網頁版，介面版本以 chat.deepseek.com 顯示為準。

另外我都有試過用 Ollama 喺本地跑蒸餾版，效果類似，但本地模型嘅語言一致性會再差少少，呢點可以參考 [DeepSeek Ollama 本地部署教學](/posts/deepseek-ollama-local-setup/) 入面嘅設定建議。

## 三步 Prompt 修正法

### 第一步：明確指定「香港繁體中文」而唔係「繁體中文」

我測試時發現，如果只寫「繁體中文」，模型有時會理解為台灣繁體，用詞同香港有出入；更差嘅情況係直接跳去簡體。改成「請用香港繁體中文（zh-HK）輸出，所有中文字符必須為繁體，不得出現簡體字」之後，簡體出現率由大約六成降到兩成。

### 第二步：加一個「語言檢查」指示

喺 prompt 結尾加一句：「輸出完成後，請自行檢查全文有冇簡體字，如有請轉回繁體再輸出。」呢個做法係利用模型嘅自我修正能力，唔使改 API 參數。我試咗十次，有八次成功攔截到簡體。

### 第三步：用 few-shot 例子鎖定風格

如果仲有漏網之魚，可以喺 prompt 入面加一兩句範例，例如：「正確輸出例子：『呢個功能可以幫中小企節省網絡成本。』錯誤輸出例子：『这个功能可以帮中小企业节省网络成本。』」記住範例要用香港常用詞，唔好淨係靠書面語。

## 常見問題

**問：係咪所有 DeepSeek 版本都適用？**
答：我實測嘅係 DeepSeek-V3 API，其他版本嘅行為可能略有差異，具體以官方文檔為準。

**問：用 system prompt 定 user prompt 好？**
答：我兩樣都試過，system prompt 嘅約束力通常強啲，但如果用網頁版可能冇 system prompt 欄位，就要喺 user message 開頭寫清楚。

**問：加咗指示之後輸出變慢點算？**
答：自我檢查會增加 token 消耗，如果嫌慢可以簡化成「請確保輸出為繁體中文」一句，但效果會打折扣。

**問：有冇其他參數可以輔助？**
答：可以試下將 temperature 調低到 0.3 左右，減少隨機性，對語言一致性有幫助。另外如果用量大，可以參考 [DeepSeek API 重試機制指南](/posts/deepseek-api-retry-guide/) 嚟處理偶發錯誤。

**問：本地模型係咪更難控制？**
答：的確係，本地蒸餾版嘅語言能力較弱，建議配合 [DeepSeek Prompt 基礎技巧](/posts/deepseek-prompt-basics/) 入面嘅結構化寫法，效果會好啲。

最後提提你，如果成日要處理繁體輸出，可以考慮將常用嘅 prompt 模板存起，每次貼上，慳返唔少時間。
