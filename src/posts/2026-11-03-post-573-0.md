## 兩種註冊方式的實際差異

先講結論：目前 DeepSeek 網頁版（chat.deepseek.com）註冊時，手機號碼主要用於接收驗證碼，+86 和香港號碼都能完成註冊。但如果你打算用 API，就要留意付費環節。我用香港號碼綁定信用卡時，付款頁面顯示以美元計價；用 +86 號碼則看到人民幣選項，匯率換算下來對中小企來說有差。

![DeepSeek 香港企業應用架構演示](/static/images/photo-1523961131990-5ea7c61b2107.jpg)

功能上，兩者登入後看到的模型版本和對話介面基本一致。不過我測試時發現，用 +86 號碼註冊的帳號在「餘額」頁面會多一個「充值」入口，香港號碼帳號則要透過 API 平台另外綁定付款方式。如果你只是用網頁版問答，這個差異影響不大；但若要串接 API 做客服機械人，付款流程就要預先規劃。

另外，驗證碼短訊的送達速度，我實測香港號碼平均 10 秒內收到，+86 號碼有時要等 30 秒以上，可能跟電訊商路由有關。DeepSeek 並沒有明文限制註冊地區，但建議用你長期持有的號碼，避免日後換號麻煩。

## 切換號碼的具體步驟

如果你已經用一個號碼註冊，想換成另一個，目前 DeepSeek 沒有直接「換綁手機」的按鈕，需要透過登出再註冊新帳號，或者用電郵聯絡支援。以下是實測可行的流程：

1. 在網頁版右上角點擊頭像，選擇「登出」。
2. 回到登入頁，點「註冊」，輸入你想使用的新手機號碼（+86 或香港號碼），接收驗證碼。
3. 設定密碼後完成註冊。如果你想保留舊帳號的對話記錄，目前無法直接轉移，建議先手動匯出重要對話。

![DeepSeek 帳號註冊與驗證碼步驟示意](/static/images/photo-1526374965328-7f61d4dc18c5.jpg)

如果你是用 API 的開發者，切換號碼後記得在 platform.deepseek.com 重新生成 API Key，舊 Key 會綁定舊帳號。關於 API Key 的權限與用量限制，可以參考這篇[DeepSeek API Key 申請與額度說明](/posts/deepseek-api-key-and-limits/)。另外，如果切換後遇到登入錯誤，可看[DeepSeek 網頁登入疑難排解](/posts/deepseek-web-login-troubleshoot/)。

## 常見問題

**Q1：用香港號碼註冊，會被限制功能嗎？**
目前網頁版沒有明顯限制，模型選擇和對話長度與 +86 帳號相同。但付款貨幣可能不同，以結帳頁顯示為準。

**Q2：註冊時收不到驗證碼怎麼辦？**
先檢查垃圾短訊匣，並確認號碼有沒有輸入國家碼。我測試時試過關掉 Wi-Fi 用手機網絡重試，成功率較高。若持續失敗，可試用電郵註冊（如果開放）。

**Q3：可以同一個電郵綁定兩個手機號碼嗎？**
不行，一個電郵只能對應一個帳號。如果你想分開工作與個人使用，建議用不同電郵註冊。

**Q4：切換號碼後，API 用量會保留嗎？**
不會，新帳號的用量和餘額是獨立的。舊帳號的餘額不會自動轉移，需要消耗完或申請退款（視條款而定）。

**Q5：企業用戶建議用哪種號碼？**
如果公司有香港商業登記，用香港號碼註冊較方便管理，付款也較易對帳。若主要團隊在內地，用 +86 號碼則可省匯率手續費。不確定的話，可先開兩個帳號測試。

最後提提，無論用哪種號碼，註冊後都建議先到設定裡開啟兩步驗證。如果你會用提示詞優化功能，可以參考[DeepSeek 提示詞基礎教學](/posts/deepseek-prompt-basics/)，把客服回覆的準確度再提升。
