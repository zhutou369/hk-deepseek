## 點解要理聯網搜索開關

上週我用 DeepSeek 網頁版（chat.deepseek.com，2025 年 1 月介面）幫公司查「香港強積金供款上限 2024/25 年度」嘅最新數字。第一次我冇留意個開關，直接問，佢答咗一個 2023 年嘅舊數。我開返聯網搜索再問，答案先至更新到 2024 年 4 月生效嘅新上限。

呢個差異好實際：聯網搜索關閉時，模型只靠訓練數據答題，資料有機會滯後；開啟後，佢會嘗試抓取實時網頁，但唔代表一定啱。關鍵係你要知個開關喺邊、幾時開、同埋點樣驗證佢引咗啲乜。

## 第一步：確認版本同開關位置

我測試時用嘅係網頁版，輸入框下面有個「聯網搜索」掣，預設係關。手機 App 就要喺對話設定入面搵「web search」選項。如果你用 API，就要喺請求參數入面加 `tools` 或相關欄位，具體欄位名以官方文檔為準。

操作步驟好簡單：

1. 打開 chat.deepseek.com，登入後開始新對話。
2. 喺輸入框下方點擊「聯網搜索」圖示，見到佢變色或顯示「已開啟」先算成功。
3. 問一條有時效性嘅問題，例如「今日香港天氣」或「2025 年 1 月美元兌港元匯率」，觀察答案有冇附上來源連結。

如果開咗之後答案仍然冇來源，可能係該問題唔適合聯網抓取，或者你嘅網絡環境阻擋咗。呢個時候可以試下切換網絡，或者用 API 配 retry 機制，詳情可以參考 [DeepSeek API 重試機制教學](/posts/deepseek-api-retry-guide/)。

## 第二步：用具體日期測試時效

聯網搜索唔係萬能。我試過問「2024 年施政報告重點」，開咗聯網之後，佢引咗政府新聞網同幾間媒體，答案入面有明確日期。但如果你問「最新施政報告」，佢有機會混淆年份。

所以問題入面最好寫明日期或年度。例如：

- 差：「香港最低工資幾多？」
- 好：「2025 年 5 月 1 日起香港法定最低工資時薪係幾多？」

另外，你要留意答案入面有冇標明「截至某日期」。如果冇，就要自己再查。我通常會要求佢：「請列出你引用嘅來源同埋每條來源嘅發布日期。」呢句 prompt 好使好用，詳細技巧可以睇 [DeepSeek Prompt 基礎教學](/posts/deepseek-prompt-basics/)。

## 第三步：核對引用連結

呢步最多人跳過。聯網搜索畀你嘅連結，唔代表內容一定啱。我試過佢引一條論壇帖當成官方數據，一撳入去就知中伏。

核對方法：

1. 逐條撳開來源連結，睇域名係咪可信（政府 .gov.hk、大學、知名媒體）。
2. 睇發布日期，確認係咪喺你問題嘅時間範圍內。
3. 如果來源係 PDF 或報告，快速掃描有冇你問嗰個具體數字。
4. 如果搵唔到，就叫佢「只引用官方網站或政府公告」，再問一次。

記住，聯網搜索係幫你搵料，唔係幫你判斷真偽。尤其講到錢、法例、醫療，一定要自己 double check。如果你用 API 大量查詢，建議配合 [API Key 與用量限制說明](/posts/deepseek-api-key-and-limits/) 去控制成本同埋記錄每次引用。

## 常見問題

**問：開咗聯網搜索係咪一定拿到最新資料？**
答：唔係。佢只會抓取公開網頁，如果該資料未被索引、或者網站阻止抓取，佢就可能用返舊數據。答案有機會混合新舊資訊，所以要自己睇來源日期。

**問：點解我開關之後，答案好似冇分別？**
答：有兩個可能。一係你問嘅問題本身唔需要實時資料（例如數學題），二係該次搜索失敗但模型冇講。你可以問「你有冇用到聯網搜索？請列出今次搜索嘅來源」，睇佢點答。

**問：API 有冇聯網搜索？**
答：截至 2025 年 1 月，API 嘅聯網功能同網頁版未必完全一致，具體參數同收費以官方文檔為準。如果你只係間中查資料，用網頁版開關最直接。

**問：聯網搜索會唔會泄露我嘅查詢？**
答：你嘅問題會用嚟生成搜索請求，呢點同一般網頁搜索類似。如果涉及公司敏感資料，建議唔好開聯網，或者用本地部署方案，可以參考 [Ollama 本地架設教學](/posts/deepseek-ollama-local-setup/)。

**問：點樣知道引用係咪可靠？**
答：最快方法係睇域名同日期。其次係交叉比對：搵多一條獨立來源，睇數字有冇出入。如果兩條來源矛盾，以官方或最新發布為準。

## 小結

聯網搜索開關唔係「開咗就勁」，而係一個要配合日期、來源核對嘅工具。我通常嘅做法係：先關聯網問一次，睇下模型本身知幾多；再開聯網問同一條，比較答案差異；最後逐條來源撳入去睇。呢個流程雖然多花幾分鐘，但對於中小企做市場調查、合規查詢嚟講，穩陣好多。
