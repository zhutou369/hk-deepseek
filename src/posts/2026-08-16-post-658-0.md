## 實戰教學：三步搞掂網站掃描

### 第一步：執齊網站資料同 DeepSeek 鎖匙 (API Key)

首先，你需要工具去掃晒你網站上嘅所有URL。市面上有好多工具可以揀，例如 Screaming Frog SEO Spider，又或者你自己用Python寫個Scrapy script都得。掃到晒URL之後，仲要抽埋每個頁面嘅完整HTML內容（起碼係文章主體內容啦）。呢啲就係 DeepSeek 分析嘅「糧食」。同時，記得去 DeepSeek 平台申請你嘅 API 憑證。如果唔識點搞，可以睇吓呢篇[DeepSeek API Key 申請與用量限制](/posts/deepseek-api-key-and-limits/)嘅文章，包你搞得掂！

### 第二步：寫個腳本搵死link

跟住落嚟，就係寫個腳本check晒每個URL。呢個腳本會對每個URL發HTTP GET請求，睇吓佢回覆咩狀態碼。如果係4xx (好似404 Not Found) 或者5xx (伺服器出錯)，咁好大機會就係死link啦。不過有時啲死link唔係咁簡單，可能重定向咗去個冇用嘅頁面。你可以set個rule，例如重定向太多次、或者內容短到冇嘢咁，嚟幫手判斷。為咗個腳本行得穩陣，處理大量請求嗰陣，你可能要考慮埋點樣處理錯誤同埋重試。雖然呢篇[DeepSeek API 請求重試策略](/posts/deepseek-api-retry-guide/)主要係講API請求，但入面講嘅重試邏輯，你可以參考吓，應用到你個死鏈檢測腳本度。

### 第三步：DeepSeek 幫你評定內容好壞

當你儲夠晒網站內容之後，就可以用 DeepSeek 大模型去評分啦！最關鍵就係設計一個靚嘅提示詞 (Prompt)。你可以將文章內容掟畀 DeepSeek，叫佢評估吓原創性、資訊量、有無語法錯、係咪堆砌關鍵字，甚至畀埋改善建議你。舉個例：

```
你係一個好有經驗嘅網站內容編輯。請幫我評估以下文章嘅質量，畀個1-5分（1分超差，5分超正）。講清楚優點同缺點，特別留意內容係咪原創同埋有無價值。文章內容：[貼文內容]
```

DeepSeek 會好詳細咁分析同畀分。你仲可以再「chur」盡啲個提示詞，例如叫佢標籤出邊啲段落可能係抄人嘢，或者列出邊啲資訊過時咗。學識[提示詞優化技巧](/posts/deepseek-prompt-basics/)係用DeepSeek 用得好嘅秘訣嚟㗎！不斷試同調整，你就會發現佢出嘅結果會越嚟越啱你心水。
