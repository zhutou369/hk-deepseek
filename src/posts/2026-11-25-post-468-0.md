## 點解要關心多設備登入？

上週升級咗 DeepSeek 網頁版（2025 年 4 月版本）之後，我特登用一部 iPhone、一部 Windows 筆記本同埋瀏覽器分頁，同時登入同一個帳號做測試。原因好簡單：香港好多中小企老闆同前線同事，朝早用手機問完客服問題，返到公司想喺電腦繼續跟，如果對話唔同步，就要重新打過條 prompt，好浪費時間。

呢篇唔係白皮書，係我實際踩過嘅操作記錄，重點放喺「點樣設定」同「實際會遇到咩情況」。

## 實測版本與環境

我測試時用嘅係 DeepSeek 網頁版（chat.deepseek.com，2025 年 4 月更新）同 iOS App（版本 1.3.2）。Android 同桌面客戶端我冇逐一試，但同步邏輯應該一致，以官方文檔為準。

有一點要留意：DeepSeek 嘅對話歷史係跟帳號綁定，唔係跟裝置。即係話你用同一個帳號登入，理論上邊部機都見到同一批對話。但「同時在線」同「即時同步」係兩回事，下面會講清楚。

## 三步設定同步

### 第一步：統一用同一個登入方式

DeepSeek 支援電郵同第三方登入。我試過用電郵註冊嘅帳號，喺手機用 Google 登入，結果開咗另一個新帳號，對話完全唔見。所以第一步係確認所有裝置都用同一個登入方法。如果你唔肯定，去設定頁睇吓綁定咗邊個電郵。

### 第二步：喺每部裝置主動刷新對話列表

登入之後，唔好以為個列表會自動彈出最新對話。我測試時發現，手機問完之後，電腦端要手動下拉刷新或者撳一下側邊欄，先會見到新對話。呢個步驟好重要，尤其係你想喺電腦繼續手機未問完嘅話題。

### 第三步：檢查「對話保留」設定

喺網頁版設定入面，有一個關於對話歷史嘅選項（具體名稱以官方文檔為準）。我建議開啟「保留對話記錄」，否則登出之後可能搵唔返之前嘅內容。呢個設定對多設備同步嘅影響最大，因為佢決定咗對話會唔會存喺雲端。

## 同步規則實際表現

我實測咗幾個場景，整理如下：

| 場景 | 結果 |
|------|------|
| 手機提問，電腦刷新 | 見到新對話，但需要手動刷新 |
| 電腦編輯對話標題，手機 | 幾秒內同步，正常 |
| 兩部機同時開同一對話 | 可以，但唔建議同時輸入，以免覆蓋 |
| 登出再登入 | 對話仍在，前提係冇清除瀏覽器數據 |

有一個位要小心：如果你喺手機用「無痕模式」登入，對話唔會保存到帳號，電腦端自然見唔到。呢點同好多網頁應用一樣，唔係 DeepSeek 特有。

## 常見問題

### 點解手機見到對話，電腦見唔到？

最大機會係登入方式唔同，或者電腦端未刷新。先確認兩邊係同一個帳號，然後手動刷新一次。如果都唔得，檢查瀏覽器有冇封鎖 cookie。

### 可唔可以兩部手機同時登入？

可以，但同時操作同一個對話可能會出現混亂。我建議一部機做主要輸入，另一部用嚟睇。

### 對話歷史會保留幾耐？

呢個問題官方冇公開明確時限，以官方文檔為準。我嘅做法係重要對話自己備份，唔好完全依賴雲端。

### 登入時彈出錯誤碼點算？

我試過見到「Too many requests」之類嘅提示，通常係短時間內登入太多次。等幾分鐘再試，或者參考站內嘅 [DeepSeek 網頁登入疑難排解](/posts/deepseek-web-login-troubleshoot/) 入面有逐步檢查方法。

### 用 API 同網頁版嘅對話會唔會同步？

唔會。API 同網頁版係兩個獨立系統，API 嘅請求唔會出現在網頁對話列表。如果你想用 API 做自動化，可以睇 [DeepSeek API 重試機制教學](/posts/deepseek-api-retry-guide/)，入面有講點樣處理失敗請求。

## 小結

多設備同步唔算複雜，但就要記住三個關鍵：同一個登入方式、手動刷新、開啟對話保留。我測試完之後，已經將公司同事嘅帳號統一用電郵登入，減少出錯。如果你只係一般用戶，記住唔好開無痕模式問重要問題就夠。
