## 點解要註銷？先諗清楚

上個月有個做中小企客服嘅朋友問我，佢試用完 DeepSeek 想刪號，但驚重新註冊會唔會影響舊資料。我測試時發現，註銷係 irreversible（不可逆轉）嘅操作，一 confirm 咗，聊天記錄、API 金鑰、帳單資料全部清走，冇得救。所以動手之前，最好先匯出你需要嘅對話紀錄。

如果你只係想換綁手機號或者電郵，唔一定要註銷。但如果你真係想徹底刪除資料，或者想用同一個手機號重新開一個乾淨帳號，咁就要跟住下面嘅步驟。

## 實測註銷三步曲（2025 年 3 月版）

我上週用網頁版（chat.deepseek.com）實測過，流程如下：

**第一步：登入後進入「設定」**

點擊右上角頭像，選擇「帳號設定」，再揀「安全與私隱」。喺呢一頁你會見到「註銷帳號」嘅選項。注意：手機 App 版本可能收埋喺「關於」入面，如果搵唔到，建議用瀏覽器登入網頁版操作。

**第二步：確認身份與冷靜期**

系統會要求你輸入手機驗證碼或者電郵驗證碼。驗證成功後，畫面會顯示一個 7 日嘅冷靜期（cooling-off period）。喺呢 7 日內，你仍然可以登入並取消註銷。我測試時發現，冷靜期內你的帳號會處於「凍結」狀態，無法使用 API，但資料尚未永久刪除。

**第三步：冷靜期屆滿後自動刪除**

7 日之後，系統會永久刪除你的帳號同相關資料。如果你想加快流程，部分地區嘅用戶可以喺冷靜期內聯絡客服要求即時刪除，但以官方文檔為準，唔保證一定得。

## 重新註冊要注意的手機號與電郵

註銷完成後，你可以用同一個手機號碼或者電郵地址重新註冊。不過有幾點要留意：

- **冷靜期內不能重新註冊**：如果你喺 7 日冷靜期內嘗試用同一手機號註冊，系統會提示「該號碼已被使用」。必須等冷靜期結束、資料正式刪除後，先可以重新註冊。
- **API 金鑰會失效**：重新註冊後，你之前生成嘅 API 金鑰全部會失效，需要重新去 [DeepSeek 開放平台](https://platform.deepseek.com) 申請。如果你有寫程式呼叫 API，記得更新金鑰。
- **免費額度可能重置**：重新註冊嘅新帳號通常會獲得新用戶免費額度，但具體金額以官方公告為準。如果你只係想攞多一次免費額度，建議睇清楚條款，唔好違規。

另外，如果你之前用 Google 或者 GitHub 第三方登入，註銷後再註冊時，建議直接用返同一個第三方帳號登入，避免混淆。

## API 用家特別提醒

如果你係用 API 嘅開發者，註銷前請先到平台撤銷所有 API 金鑰，並確保你嘅應用程式已經改用其他後備方案。我試過有一次忘記撤銷，結果註銷後個 app 狂報 401 錯誤，搞咗半個鐘先搞清楚咩事。

想避免呢種情況，可以參考站內嘅 [API 金鑰與用量限制教學](/posts/deepseek-api-key-and-limits/)，入面有講點樣管理金鑰同監控用量。另外，如果你嘅程式需要處理錯誤重試，可以睇埋 [API 重試機制指南](/posts/deepseek-api-retry-guide/)，咁就唔會因為金鑰失效而手忙腳亂。

## 常見問題

**Q1：註銷後，我之前嘅對話記錄仲可以搵返嗎？**

唔可以。一旦過了冷靜期，所有對話記錄會永久刪除，無法復原。建議註銷前先手動匯出重要對話。

**Q2：我可唔可以只刪除部分對話，而唔註銷帳號？**

可以。喺對話歷史入面，你可以逐條刪除對話。不過呢個操作只係刪除對話紀錄，唔會刪除帳號本身。如果你想徹底刪除所有資料，就要註銷帳號。

**Q3：註銷後，我用同一個電郵再註冊，會唔會自動恢復舊資料？**

唔會。重新註冊等於開一個全新帳號，舊資料已經被刪除，唔會轉移過去。

**Q4：冷靜期內我反悔，點樣取消註銷？**

只要喺 7 日內重新登入，系統會提示你「取消註銷」，點擊確認即可恢復帳號。

**Q5：如果我用微信或者 Apple ID 登入，註銷流程一樣嗎？**

流程大同小異，但驗證方式可能略有不同。以官方文檔為準，或者喺設定頁面睇清楚指示。
