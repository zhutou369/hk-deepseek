DeepSeek 在 2025 年 2 月的註冊流程中，部分香港手機號碼用戶無法收到短訊驗證碼。這篇文章會拆解收唔到驗證碼的兩個主要原因，並提供實測有效的解決步驟，幫你順利完成註冊。

問題主要分為兩類：電訊商層面的短訊攔截，以及 DeepSeek 系統對特定號碼段的限制。我測試咗幾個解決方法，包括更換接收號碼、調整手機設定、使用替代註冊方式，最終搵到可行方案。以下會逐步說明每個方法的操作細節同成功率。

上星期幫朋友註冊 DeepSeek，用香港手機號碼撳咗幾次「發送驗證碼」都冇反應。起初以為係網絡問題，後來發現唔少香港用戶都遇到同樣情況。我測試時發現，問題多數同短訊過濾或電訊商攔截有關，唔一定係平台壞咗。以下係我實測有效嘅流程，適合普通用戶跟住做。

## 點解收唔到驗證碼？先睇兩個常見原因

第一個原因係手機嘅垃圾短訊過濾。唔少香港手機預設開啟「過濾未知寄件者」，而 DeepSeek 嘅短訊發送號碼可能被歸類為推廣訊息。第二個原因係電訊商層面嘅攔截，尤其係儲值卡或部份虛擬營運商號碼，有機會收唔到海外短訊。

我上週升級咗手機系統後，特意檢查短訊過濾設定，發現「過濾未知寄件者」係開住嘅。關閉之後再試，驗證碼就順利收到。如果你用緊 iPhone，可以去「設定 > 訊息 > 未知與垃圾訊息」睇睇；Android 就在「訊息」App 嘅設定入面搵「垃圾訊息保護」。

## 實測解決步驟（2025 年 2 月版本）

以下步驟按順序做，大部分情況可以解決。我測試時用嘅係 DeepSeek 網頁版（2025 年 2 月介面），手機型號係 iPhone 13，網絡為數碼通。

### 步驟一：檢查短訊過濾與封鎖名單

先入去手機嘅短訊設定，確認冇封鎖 DeepSeek 嘅發送號碼。同時檢查「封鎖的聯絡人」清單，睇下有冇誤加。呢一步好簡單，但最多人忽略。

### 步驟二：改用語音驗證（如果支援）

喺驗證碼輸入頁面，留意有冇「改用語音通話」嘅選項。我測試時見到有「致電給我」嘅按鈕，撳之後會接到自動語音來電，讀出六位數字驗證碼。呢個方法對短訊過濾問題特別有效。如果冇呢個選項，以官方文檔為準，可能部分地區未開放。

### 步驟三：轉用其他網絡或等待十分鐘再試

有時係短訊閘道延遲。我試過連續撳發送，結果等咗十五分鐘先收到第一條。建議撳一次之後等十分鐘，其間可以切換 Wi-Fi 同流動數據，或者重啟手機。如果仍然唔得，可以試下用另一張香港電話卡（例如 csl、1010）測試，以確認係咪特定電訊商問題。

![DeepSeek 註冊流程中檢查網絡與驗證碼畫面](/static/images/photo-1581092921461-eab62e97a780.jpg)

### 步驟四：聯絡支援（最後手段）

如果以上都唔得，可以去 DeepSeek 官網嘅幫助中心提交問題，寫明你嘅電話號碼、註冊時間同錯誤情況。我朋友試過等咗兩日先收到回覆，所以建議同時試用電郵註冊（如果平台允許）。另外，如果你只係想試用模型，可以考慮用 [Ollama 本地架設 DeepSeek](/posts/deepseek-ollama-local-setup/)，完全唔使驗證碼。

## 常見問題

**問：用香港號碼係咪一定收唔到驗證碼？**

唔一定。我實測數碼通同 csl 號碼都收到，但部份儲值卡或虛擬營運商號碼有機會失敗。如果試咗以上步驟都唔得，建議直接聯絡你嘅電訊商查詢短訊接收設定。

**問：驗證碼有效期幾耐？**

一般為 10 分鐘，以官方頁面顯示為準。過期就要重新發送。

**問：可唔可以用同一號碼註冊多個帳號？**

平台通常限制一個號碼只能綁定一個帳號，具體規則以官方文檔為準。

**問：註冊後登入唔到點算？**

可以參考站內嘅 [DeepSeek 網頁版登入疑難排解](/posts/deepseek-web-login-troubleshoot/)，入面有步驟檢查瀏覽器同網絡設定。

**問：驗證碼收唔到，會唔會影響 API 使用？**

API 係另一套系統，用 API Key 就得，唔使短訊驗證。如果你想知 API Key 點攞同有咩限制，可以睇 [DeepSeek API Key 申請與額度說明](/posts/deepseek-api-key-and-limits/)。
